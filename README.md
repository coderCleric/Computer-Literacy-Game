A game designed to teach late middle-school and early high-school students how to better use and organize the digital file system.<br />
The "Computer Literacy Game" folder is the root folder of the Unity project that was used to make the game, while the "Data Analysis" folder contains the raw data collected during experimentation, as well as the Python scripts used to analyze the data.

# Data Files
The following files are included in the data:
- completions.csv - The research IDs that successfully completed the game.
- demographic_survey.csv - The results from the demographic survey.
- ids.csv - The full list of IDs that were registered to the database.
- posttest.csv - The results of the posttest.
- pretest.csv - The results of the pretest.
- puzzledata.csv - Information taken directly from gameplay, showing how participants performed in the game.
- survey_openended_breakdown.csv - Keywords taken from the open-ended section of the usability survey.
- usability_survey.csv - The results of the usability survey.

For each of these files, there are the following versions:
- V0 - Completely raw, originally collected data.
- V1 - Culled data, with invalid IDs and incomplete submissions removed.
- V2 - Further culled data, where certain instances of students getting confused and replaying the game are removed.
